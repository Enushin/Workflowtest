# Workflowtest

GitHub ワークフローのテスト用リポジトリです。

## 概要

このリポジトリは GitHub Actions ワークフローの動作を試験・検証するために作成されました。

## セットアップ

```bash
npm install
```

## スクリプト

### リンター実行

```bash
npm run lint
```

ESLint を使用してコードの静的解析を実行します。

### テスト実行

```bash
npm test
```

現在はプレースホルダーのみです。

## ファイル構成

- `package.json` - npm パッケージ設定
- `eslint.config.js` - ESLint 設定（フラット設定形式）
- `index.js` - サンプル JavaScript ファイル
- `README.md` - このファイル
